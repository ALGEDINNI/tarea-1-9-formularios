¿Qué problema de seguridad descubres en el historial por haber enviado la inscripción con GET? ¿Qué método recomienda el artículo para un formulario como este y por qué?

Al abrir el historial, se puede ver que los datos del formulario son visibles en la URL como por ejemplo la clave que he usado para mis datos, lo que puede ser un riesgo si contienen información como contraseñas o datos personales. El artículo recomienda usar el método POST para enviar datos sensibles, ya que estos no se muestran en la URL. En POST, los datos se envían en el cuerpo de la solicitud, lo que los hace invisibles en la URL.

¿Qué ocurre al enviar la inscripción con POST? Según el artículo, ¿qué tendría que haber en el servidor para procesar esos datos?

Al enviar la inscripción con POST, me saltó el error "405 Method Not Allowed". Según el artículo, para procesar los datos enviados con POST, el servidor necesitaría tener un script o programa configurado para recibir y manejar solicitudes POST.
